# 🔍 Умный поиск файлов (Smart File Search)

Легкий, быстрый Python-скрипт без зависимостей, предназначенный для поиска точных слов или фраз **внутри** содержимого нескольких текстовых файлов одновременно. Идеально подходит для разработчиков, аудиторов и всех, кому необходимо сканировать большие объемы текста.

## ✨ Основные возможности

* **Глубокий внутренний поиск:** Сканирует фактическое содержимое файлов, а не только их имена.
* **🌍 Встроенный мультиязычный интерфейс:** Динамическое меню доступно на **испанском, английском, русском и клингонском (tlhIngan Hol)** языках. Язык можно изменить на лету из главного меню.
* **🎯 Точные фильтры:** Ограничьте поиск, указав корневую папку, определенные расширения (например, `.txt, .py, .log`) и обязательные слова в имени файла.
* **📖 Умный контекст:** Печатает строки текста непосредственно до и после совпадения, чтобы понять контекст без открытия оригинального файла.
* **💾 Менеджер профилей:** Сохраняйте повторяющиеся параметры поиска и быстро загружайте их в будущих сеансах.
* **📤 Экспорт результатов:** Сохраните весь отчет о совпадениях и его контекст в чистом файле `.txt` для последующего просмотра.
* **📦 Ноль зависимостей:** Создан исключительно с использованием стандартных библиотек Python (`os`, `sys`, `json`, `re`). Работает на Windows, Linux, macOS и Android (через Termux/Pydroid).

## 🚀 Требования и установка

Все, что вам нужно, это **Python 3.6+**, установленный в вашей системе. Нет необходимости устанавливать пакеты через `pip`.

1. Клонируйте этот репозиторий или скачайте файл `busca.py`:
   ```bash
   git clone https://github.com/asesoriaogam-collab/py-interactive-grep.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd repo-name
   ```
3. Запустите скрипт:
   ```bash
   python busca.py
   ```

## 🛠️ Основное использование

При запуске скрипта вас встретит интерактивное консольное меню:

1. **Настройки:** Здесь вы можете определить папку для сканирования, расширения (по умолчанию `.txt`), включить контекст и управлять своими профилями.
2. **Начать поиск:** Запускает поисковую систему с запросом точного слова или фразы для поиска.
3. **Выбор языка:** Позволяет мгновенно переключать интерфейс между доступными языками.
4. **Выход:** Безопасное закрытие приложения.

### 💡 Пример рабочего процесса
* Зайдите в Настройки -> Установите поиск в расширениях `.log` и включите 2 строки контекста.
* Начать поиск -> Искать слово `ERROR`.
* Скрипт покажет вам точно, в каких файлах `.log` это произошло, и напечатает две строки кода до и после каждой ошибки.
* В конце экспортируйте результаты в `error_report.txt`.
