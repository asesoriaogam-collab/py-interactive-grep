# 🔍 teywi' nejwi' (Smart File Search)

Python script mach, nom je. ghap pagh lI'bogh tu'lu'. mu'mey mu'tlheghmey je teywi'mey **qoD**Daq nejmeH chenmoHlu'pu'. chu'wI'pu', ghotpu' nejbogh je lI'qu'.

## ✨ Qapmey lI'qu'

* **qoD nejchu':** teywi' pong neH nejbe', teywi' qoD nejchu'.
* **🌍 pImbogh Holmey:** **tlhIngan Hol**, ruSya' Hol, DIvI' Hol, eSpa'nya' Hol je tu'lu'. yor pa'Daq Hol choHlaH.
* **🎯 NgaSnISbogh:** teywi' pa', teywi' pong Deghmey Qav (`.txt, .py, .log`), teywi' pong NgaSnISbogh je yIwIv.
* **📖 DungDaq bIngDaq je:** mu' tu'lu'bogh DungDaq bIngDaq je tlheghmey cha', vaj teywi' poSmoHbe'lu'mo' mIyaj.
* **💾 ta'mey pol:** QapmeH wIvmeylIj yIpol, pIq yIlIgh.
* **📤 pol:** nej poQ DungDaq bIngDaq je `.txt` teywi'Daq yIpol.
* **📦 pagh Hup:** Python tIgh (`os`, `sys`, `json`, `re`) neH lo'. Windows, Linux, macOS, Android (Termux/Pydroid) jeDaq Qap.

## 🚀 poQlu'bogh lIghlu'bogh je

**Python 3.6+** neH poQlu'. `pip` lo'lu'be'.

1. teywi'mey tIpol qoj `busca.py` yInIH:
   ```bash
   git clone https://github.com/asesoriaogam-collab/py-interactive-grep.git
   ```
2. teywi' pa'Daq yIjaH:
   ```bash
   cd repo-name
   ```
3. script yIqem:
   ```bash
   python busca.py
   ```

## 🛠️ lo' mIw

script yIqemDI', yor pa' yIbej:

1. **QapmeH wIvmey (Config):** teywi' pa', teywi' pong Deghmey Qav (`.txt`), DungDaq bIngDaq je, ta'mey je yIwIv.
2. **nej (Start search):** nejwi' yIchu', mu' yIghItlh.
3. **Hol wIma' (Language):** Hol choHlaH.
4. **mej (Exit):** Qaw'Ha'.

### 💡 lI'bogh mIw
* QapmeH wIvmey yIjaH -> `.log` yIwIv, cha' tlheghmey yIQaw'.
* nej -> `Qagh` (ERROR) mu' yInej.
* `.log` teywi'meyDaq qaSbogh cha', Qagh DungDaq bIngDaq je cha' tlheghmey cha'.
* QavDaq, nej poQ `Qagh_ta.txt` teywi'Daq yIpol.
